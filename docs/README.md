# Documentation Directory

## Tổng Quan

Thư mục `docs/` chứa tất cả tài liệu được phân loại theo mục đích:

## Cấu Trúc

```
docs/
├── guides/           # Hướng dẫn chi tiết
├── explanations/     # Giải thích kỹ thuật
└── quickstart/       # Hướng dẫn nhanh
```

## Phân Loại

### 1. **Guides** - Hướng dẫn chi tiết
- `BEAMFORMING_GUIDE.md` - Hướng dẫn beamforming
- `REFERENCE_BEAMFORMING_GUIDE.md` - Hướng dẫn reference beamforming
- `README_localization.md` - Hướng dẫn localization
- `README_audio_filtering.md` - Hướng dẫn filtering

### 2. **Explanations** - Giải thích kỹ thuật
- `FILTER_EXPLANATION.md` - Giải thích digital filtering
- `GIAI_THICH_REFERENCE_BEAMFORMING.md` - Giải thích thuật toán
- `AUDIO_PROCESSING_COMPARISON.md` - So sánh kỹ thuật
- `REFERENCE_BEAMFORMING_CPP_ANALYSIS.md` - Phân tích C++ conversion
- `ROADMAP_CPP_CONVERSION.md` - Roadmap chuyển đổi C++
- `TIMING_PERFORMANCE.md` - Phân tích performance

### 3. **Quickstart** - Hướng dẫn nhanh
- `QUICK_START_FILTERING.md` - Hướng dẫn nhanh filtering

## Cách Sử Dụng

### Để học lý thuyết:
→ Đọc `explanations/`

### Để thực hành:
→ Đọc `guides/`

### Để bắt đầu nhanh:
→ Đọc `quickstart/`
